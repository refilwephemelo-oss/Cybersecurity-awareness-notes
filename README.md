# Cybersecurity-awareness-notes
This depository will give readers an understanding on how to protect themselves from cybercriminals and online fraud.
Cybersecurity is a growing method of protection, when it comes to the digital world. And that is why I have created this repository in order to educate people on it.
Firstly, cybersecurity such as multifactor authentication helps protect users accounts online. By requiring two step verification. This leads to users' data to be protected.
Secondly,firewalls also protect user data by blocking traffic that can cause an overhead.
Thirdly, encryption another form of cybersecurity helps protect data by it transforms information in a format that cannot be read.
